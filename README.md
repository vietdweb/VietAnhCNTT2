## 🚀 Hướng Dẫn Chạy Dự Án

### Yêu Cầu
- .NET 8 SDK trở lên
- Visual Studio Community 2026 hoặc mới hơn

### Các Bước Chuẩn Bị

1. **Clone Repository**
```bash
git clone https://github.com/vietdweb/VietAnhCNTT2.git
cd VietAnhCNTT2
```

2. **Restore Dependencies**
```bash
dotnet restore
```

3. **Build Dự Án**
```bash
dotnet build
```

4. **Chạy Ứng Dụng**
```bash
dotnet run
```
